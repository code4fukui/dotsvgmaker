# dotsvgmaker

ピクセルアートを作成し、SVGファイルとしてエクスポートできるシンプルなWebツールです。

## デモ

**ライブツール:** [https://code4fukui.github.io/dotsvgmaker/](https://code4fukui.github.io/dotsvgmaker/)

## 機能

- **リサイズ可能なキャンバス:** スライダーまたは直接入力でグリッドの幅と高さを調整できます。
- **ピクセル描画:** グリッド上のセルをクリックして、ピクセルのオン/オフを切り替えます。
- **角の丸み調整:** ピクセルの角の半径を調整し、シャープな四角形から円形まで、さまざまなスタイルに変更できます。
- **パターンのシフト:** 専用ボタンを使用して、描画全体を上下左右に移動できます。
- **ライブプレビュー:** 編集に合わせて、レンダリングされたSVGと対応するソースコードを即座に確認できます。
- **SVGエクスポート:** ワンクリックで、作成した画像をクリーンな `.svg` ファイルとしてダウンロードできます。

## 使い方

1. **グリッドサイズの設定:** 上部のスライダーと入力フィールドを使用して、キャンバスの幅と高さを指定します。
2. **描画:** グリッド上の任意のセルをクリックして、ピクセルをオン（黒）またはオフ（白）に切り替えます。
3. **スタイルの調整:** 矢印ボタンの下にあるスライダーを使用して、ピクセルの角の丸みを調整します。
4. **位置調整:** 矢印ボタン（←、→、↑、↓）を使用して、キャンバス上の描画全体を移動します。
5. **エクスポート:** 「download SVG」ボタンをクリックして作品を保存します。また、ページ上のテキストエリアからSVGのソースコードを直接コピーすることもできます。

## クレジット

このツールは [dot2svg](https://github.com/code4fukui/dot2svg/) ライブラリを使用して構築されています。
