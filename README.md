# dotsvgmaker

> 日本語のREADMEはこちらです: [README.ja.md](README.ja.md)

A simple web tool to create pixel art and export it as an SVG file.

## Demo

**Live tool:** [https://code4fukui.github.io/dotsvgmaker/](https://code4fukui.github.io/dotsvgmaker/)

## Features

- **Resizable Canvas:** Adjust the grid width and height using sliders or direct input.
- **Pixel Drawing:** Click cells on the grid to toggle them on or off.
- **Adjustable Roundness:** Control the corner radius of the pixels for different styles, from sharp squares to circles.
- **Pattern Shifting:** Move the entire drawing up, down, left, or right with dedicated buttons.
- **Live Preview:** Instantly see the rendered SVG and its corresponding source code as you edit.
- **SVG Export:** Download your creation as a clean `.svg` file with a single click.

## How to Use

1.  **Set Grid Size:** Use the top sliders and input fields to define the width and height of your canvas.
2.  **Draw:** Click on any cell in the grid to toggle a pixel on (black) or off (white).
3.  **Adjust Style:** Use the slider below the arrow buttons to control the roundness of the pixel corners.
4.  **Position:** Use the arrow buttons (←, →, ↑, ↓) to shift your entire drawing on the canvas.
5.  **Export:** Click the "download SVG" button to save your creation. You can also copy the SVG source code directly from the text area on the page.
